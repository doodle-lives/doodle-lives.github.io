Privacy policy

Effective 2026-10-06

This policy covers the Doodle Lives uploader, a private tool that uploads videos to the Doodle Lives YouTube channel. It is run by the channel owner for the channel's own account only. It is not offered to the public, and no one else can sign in to it.

What the uploader accesses

When the channel owner connects the uploader to YouTube, Google asks for permission to manage the YouTube account. The uploader uses that permission only to:

  • upload the channel's own finished videos as public videos, only after the channel owner approves each one, and
  • set each video's title, description, tags, category and language.

It does not read comments, messages, subscribers, viewing history, analytics, or any other account's data.

What is stored, and where

The sign-in token Google issues is kept as an encrypted secret in the channel's private GitHub repository, and is used only by the uploader. Job records and preview videos are kept on the channel owner's Cloudflare account, behind the owner's password. The uploader stores the ID YouTube gives each uploaded video. The uploader uses no cookies, analytics or tracking, and this website collects no personal data.

Sharing

Data received from Google is never sold, shared with third parties, used for advertising, or used to train AI models. It is sent only back to YouTube, to carry out the actions listed above.

The Doodle Lives uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

YouTube API Services

The uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.

Removing access

Access can be removed at any time from the Google account permissions page. Removing it stops the uploader immediately. To have the stored token and video IDs deleted, email the address below; they are deleted within 7 days.
